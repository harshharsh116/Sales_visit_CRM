📋 Sales Visit CRM

A web-based Sales Visit Customer Relationship Management (CRM) system developed using Python, Streamlit, MySQL, and n8n. This application helps sales teams efficiently record customer visits, manage follow-ups, and automate reminder emails.

🚀 Features
🔐 Secure Login System
👥 Role-Based Access (Admin & Salesman)
📋 Add New Sales Visits
📄 View Personal Visits
📊 Admin Dashboard
👤 User Management
📅 Follow-up Scheduling
📧 Automatic Email Reminders using n8n
🗄️ MySQL Database Integration
✅ Form Validation
📱 Mobile Number & Email Management

🛠️ Tech Stack
Frontend: Streamlit
Backend: Python
Database: MySQL
Automation: n8n
Language: Python
Version Control: Git & GitHub
